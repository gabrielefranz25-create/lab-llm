da `dev`. Dopo ogni task `python -m pytest` verde prima del commit. Eseguito in autonomia.

- [ ] **Task 1 – avvio dei server.** `tests/test_avvio_mcp.py` (server finto: stdio, http con
  host/porta/path, `MCP_HTTP_PORTA`, trasporto sconosciuto → uscita 2), poi `server_mcp/avvio.py`
  e i `__main__` dei sette server che chiamano `avvia(mcp, "<nome>")`.
  Commit `feat(mcp): server avviabili anche con Streamable HTTP`.
- [ ] **Task 2 – agente via HTTP.** Test in `tests/test_config.py` (`TRASPORTO_MCP`, `MCP_HTTP_HOST`),

  (con `url` usa `StreamableHttpTransport`), poi `agente/config.py`, `agente/mcp_ponte.py`
  (`ServerMCP.url`, log `via`), `agente/main.py` (log `trasporto MCP`), `.env.example`.
  Commit `feat(mcp): agente collegato ai server via Streamable HTTP`.

  `TRASPORTO_MCP=http python -m agente`. Commit `feat(mcp): avvio di tutti i server HTTP con un comando`.
